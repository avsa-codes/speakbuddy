# SpeakBuddy

SpeakBuddy is a platform for practicing English through structured 1-to-1 conversations and group discussions with other users.

## MVP

- User registration and JWT authentication
- User profiles with English level and interests
- 1-to-1 user matching
- Topic-based conversations
- Voice and video calls
- Real-time messaging
- Group discussion rooms
- Session history

## Tech Stack

- React + TypeScript
- Node.js + Express + TypeScript
- PostgreSQL
- Prisma
- Socket.IO
- WebRTC
- AWS
